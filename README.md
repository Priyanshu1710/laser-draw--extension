# Laser Draw — Chrome Extension

A Chrome extension that brings the [laser-draw](https://www.npmjs.com/package/laser-draw) laser pointer to any web page.

## Install (developer mode)

1. Open `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** and select this folder

## Use

- Click the extension icon and press **Turn laser on**, or press **Alt+L**
- Press **Esc** to turn it off

The page stays clickable while the laser is on.
Chrome blocks extensions on `chrome://` pages and the Chrome Web Store, so the laser won't run there.
